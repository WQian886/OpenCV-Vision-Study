# 历史快照长得和当前声明一模一样

## 核心

2026-10-26，W7 结项之后还的第七笔（欠账 11）遇到的。

给文档里的数加门禁，第一步就会撞上这个：

`notes/notes_W7_Close_2026-10.md` 里有**两张同形的表**：

```
### 3.2 数字（实测，不是推算）
| W7 套件 / 断言 | **23 / 2230** |     <- 结项那天的快照

### 3.5 结项之后又还了六笔（2026-10-25）
| W7 套件 / 断言 | **26 / 2371** |     <- 现在的数
```

**形状完全一样。** 只看表格本身，
**没有任何办法**区分哪张是「现在的声明」、哪张是「历史记录」。

## 两条走不通的路

| 做法 | 结果 |
|---|---|
| 查**所有**同形的行 | 历史快照（23 / 2230）被当成当前声明 → **误报** |
| 只查**最新**的那张 | 「最新」是猜的 → 文档一改顺序就错，**而且是静默错** |

更糟的是第三种：

> 「查不到的就跳过」 ——
> 检查器安静地只查了它认得的那张，
> 另一张**根本没被查**，而**没有人知道**。

## 修法：给声明加**作用域**

检查器里每条声明可以带一个作用域标记：

```
'After' => '^### 3\.5'
```

意思是：**只看从这个小节标题到下一个标题之间的行**。

于是历史快照**既不会被误报，也不会被放过** ——
它**根本不在检查范围内**，而当前那份**在**。

⚠ 关键：作用域标记必须能**唯一定位**那一段。
`### 3.5` 是 ASCII 的，而且**不常见**。

## 为什么锚点必须用 ASCII

`.ps1` 必须是**纯 ASCII 无 BOM**（PS 5.1 按 ANSI 读无 BOM 的 .ps1，
中文会变乱码）。

于是锚点里不能写中文，只能写 ASCII 标记
（`### 3.5`、`W7`、`#else`、`atomic`、`KB`），
中文部分用 `\D+` 跨过去。

> ⚠ **乱码的匹配不报错，是静默不匹配。**
>
> 这比「匹配失败」危险得多 ——
> 「匹配失败」会红，「静默不匹配」不会。
>
> 所以检查器里**认不出声明时必须 FAIL，不能 SKIP**。
> 一条规则停下来不报，比它报错更贵。

## 教训

> **任何「和现在对不对得上」的检查，都要先回答一个问题：**
> **这份文档里有没有「过去的数」？**
>
> 有的话，就必须给每一处声明划清**作用域**。
> 划不清的两种结局都不好：
>
>   · 划得**太宽** → 历史被误报 → 大家开始无视这个门禁；
>   * 划得**太窄** → 有一块根本没查 → **假装查过了**。
>
> ⇒ 而且**宁可划窄**：
> 误报是噪声，漏查是**谎**。
