# 复刻不等于等价：两份实现连"自增在哪"都不一样

## 核心
2026-10-21 写旋钮审计时，为了定位「为什么一个算子都没扫到」，
用 Python 复刻了 C++ 的解析逻辑。

**Python 复刻是对的**，C++ 是错的。

差别在这一处：

```cpp
// C++:for 循环每次迭代结束会自动 ++i
for (int i = 0; i < n; ++i) {
    if (是块注释) {
        i += 2;                 // 跳过 "*/"
        continue;               // ← for 的 ++i 又跳了一个字符!
    }
}
```

```python
# Python:while 循环不会自动自增
while i < n:
    if 是块注释:
        i += 2                 # 跳过 "*/"
        continue               # ← 这里不会再多跳一个
```

## 实测后果
C++ 那版少跳了一个字符，而源码里恰好有这一行：

```cpp
QJsonObject ImageSourceCamera::run(const QJsonObject& params,
                                    const QJsonObject& /*inputs*/) {
```

去掉块注释后，右括号被吃掉：

```
run(const QJsonObject& params, const QJsonObject&  {      ← 没有 )
```

括号配对数错 → 整个 `run()` 函数体找不到 →
**相机的三个旋钮全被误判成"死旋钮"**。

## 教训
> **复刻不等于等价。**
> 复刻时最容易漏掉的，恰恰是那种"语言之间行为不同"的细节 ——
> 自增在哪、迭代器怎么走、异常怎么冒泡。
>
> 复刻只能用来**缩小怀疑范围**（"逻辑本身是对的，那问题在别处"），
> 不能用来**证明**原实现对。

推论：**别拿复刻当证据**。
本项目的老规矩是"注释会骗人，断言不会" ——
这里要补一句：**复刻也会骗人，而且骗得比注释还像**，
因为它读起来是"同样的逻辑"。

## 顺带
这类 bug 平时不会暴露：少一个右括号，只会让某个函数体找不到，
而找不到的**后果**是"扫到 0 个对象" —— 又是一条恒真的空断言。
