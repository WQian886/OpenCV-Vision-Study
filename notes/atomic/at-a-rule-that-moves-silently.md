# 规则会悄悄搬家 —— 代码改了形状，规则还绿着，但它检查的已经不是那件事了

## 核心
2026-10-21，第四轮（把全部旋钮迁到带类型检查的读法）遇到的。

审计里有一条规则 3d：兜底值必须来自**本算子自己的** `Defaults` 常量。
当时它查的是 `run()` 里的兜底表达式：

```cpp
const int minArea = params.value("min_area").toInt(CircleFitDefaults::kMinArea);
//                                              ↑ 3d 查的就是这一处
```

这一轮把旋钮全迁到 helper 之后，兜底变成了：

```cpp
readIntKnob(params, defaultParams(), "min_area", &minArea, &err);
//                          ↑ 兜底现在是 defaultParams()
```

`defaultParams()` 里**没有任何 `Defaults::` 引用**了 ——
所以 3d 那条检查**没有红，它只是从此什么都不查**。

## 为什么这比"规则变空断言"更阴

空断言那种（扫到 0 条 → 断言恒真）至少还留着一个**数出来的**痕迹：
"一共检查了 0 处"。

而这一种是**无声的**：

- 断言数没变（或者只是少了几条，没人数）
- 测试照样全绿
- 规则**还在跑**，只是它检查的东西换了个位置
- 而且换过去的位置**本来就该有人管** —— 少了那一层，没人知道

具体到这一轮：迁移前 3d 检查 21 处"兜底引用的是本算子的 Defaults"；
迁移后这 21 处检查消失了，而对应的检查（defaultParams() 里的引用）
本来该由**另一条规则**管 —— 那条规则当时不存在。

## 收法：规则要**搬家**，不是删掉

第三轮给 `defaultParams()` 那侧补了一条 **3i**：
「defaultParams() 里引用的 Defaults 必须是本算子的」。
检查的内容一模一样，只是**查的地方换了** —— 从"兜底"搬到"声明"。

因为迁移之后，**声明才是兜底真正指向的地方**：
兜底不再自己写一个值，它指的是 `defaultParams()`。

> 搬家的前提是：**先说清楚"现在谁说了算"**。
> 以前是"兜底自己写一个值"，所以查兜底；
> 现在是"兜底指着声明"，所以查声明。
> 不问这一句，就会把检查挂在已经废弃的形状上。

## 教训

> **改代码的形状时，先问一句："盯着这个形状的那条规则，现在盯的是哪件事？"**
>
> 答案通常不是"同一件事"——
> 代码搬家了，规则也得搬。
> 规则没搬，它不会红，它只会**变成一个检查别的东西的规则**，
> 而你以为它还在守着原来那件事。

配套的一条硬规矩（这个项目第三轮就栽过）：
**每条规则都要有"我检查到 N 处"的断言** ——
N 掉到 0 会响；N 变了但没掉到 0，**不响**。
所以还要再加一条：**规则搬家时，断言数的变化要解释**。
这一轮就因为 3d 的条数从 132 变成别的数，才发现 3i 补的位置不对。
