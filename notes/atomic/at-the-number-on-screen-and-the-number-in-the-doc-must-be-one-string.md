# 屏幕上的数和文档里的数，得是同一串字符

## 现象

2026-10-29，给 W4 补测试时，断言消息里的打印是这么写的：

```cpp
(int)(x * 10000) / 10000.0      // 想表达「四舍五入到 4 位小数」
```

于是屏幕上打出来的是：

| 屏幕上的 | 文档里引的（探针量出来的） |
|---|---|
| `0.0309` | **0.030943** |
| `0.9500` | **0.955053** |
| `0.00058` | **0.000587** |
| `0.76 像素` | **0.766 像素** |

⇒ **同一个测量，屏幕上一个数、文档里另一个数。**

## 为什么危险

不是因为差得多（差得其实很少），是因为**截断长得像四舍五入**。

`0.0309` 读起来完全像一个**精确的**数 —— 有四位小数、有上下文、
没有一个地方写着「这是截断的」。
**没人会去查一个看起来精确的数。**

> **一个看起来像精确值的近似值，比一个明显粗糙的值危险。**
>
> 明显粗糙的值（`0.03`）自己会招来质疑：「这精度够吗？」
> 看起来精确的值**不招来任何质疑**，于是它一直留在文档里。

而这个仓库栽过的最贵的一类跟头，就是「文档里写的不是量出来的那个数」。

## 根因：一次测量，两个表示

测量只发生了一次，但**那个数有两个表示**：

```
                    一次测量
                       │
        ┌──────────────┴──────────────┐
   测试的打印格式                    探针的打印格式
   (int)(x*10000)/10000.0           %.6f
        │                              │
   0.0309                          0.030943
        └──────────────┬──────────────┘
                       │
              文档引用的是右边那个
```

产生这两个表示的是**两段代码**。

⇒ 这和「抄副本」是**同一个病**：
**同一件事，在两个地方各有一份实现，抄的时候一模一样，所以看起来完全正常。**
只不过这次抄的不是代码，是**精度**。

（`at-the-copies-had-already-drifted.md` 记的是代码那一份；
`at-four-copies-of-one-number.md` 记的是**常量**那一份。）

## 修法：不是把文档改钝，是**把显示提精**

两条路：

| 做法 | 结果 |
|---|---|
| 把文档改成 `0.0309` | 精确值**丢了** —— 文档从此只能引用一个钝值 |
| 把测试改成 `%.6f` | 文档引的**就是屏幕上那一串** ✅ |

选第二条。

```cpp
static std::string fmt(double v, int digits = 6) {
    char buf[64];
    std::snprintf(buf, sizeof(buf), "%.*f", digits, v);
    return std::string(buf);
}
```

⇒ 改完之后，文档里那一串 `0.030943` **就是**测试输出的那串字符。

## 教训

> **文档里引的数，必须是某段代码打印出来的那一串字符。**
>
> 要么它就是断言消息里出现的那串，
> 要么它来自一条**写明精度**的探针命令，且**能重跑出同一串**。
>
> 「我记得是那个数」不算来源。

推论：

1. **打印格式本身是一个断言。**
   一个把 `0.030943` 打成 `0.0309` 的格式，和一个把 `>=` 写成 `>` 一样，
   是**把事实说小了**。
2. **别用整数截断来「格式化」浮点。**
   `(int)(x * 10000) / 10000.0` 是**截断**，不是四舍五入，
   而且它连自己都不像 —— 一旦被文档引用，它就成了「事实」，
   连截断这个事实都查不出来了。
   用 `printf("%.6f")` / `std::format`。
3. **文档里出现小数，就该问一句「这是几位的」。**
   答不上来，说明这个数是**抄来的精度**，不是量出来的。

## 检查清单

- [ ] 文档里那个小数，**测试也打印它吗**？打印出来是**同一串**吗？
- [ ] 那个数是探针量的吗？探针命令**还跑得起来**吗？精度**写明**了吗？
- [ ] 打印浮点用的是 `%.Nf` / `std::format`，还是**整数截断**？
- [ ] 断言消息里的数，和文档里的数，**是不是同一个来源**？
