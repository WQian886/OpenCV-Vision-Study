# 一个只在一处成立的数，不是事实，是那一处的产物

## 核心

写断言的时候，「结果是 N」几乎总比「结果在参数范围内稳定」好写 ——
于是后者很少有人写。

而**一旦这个 N 依赖着某个参数，断言就变成了给那个参数拍马屁**：
改参数的人只要顺手把断言里的 N 改掉，测试照样绿。

> **一个只在一处成立的数，不是事实，是那一处的产物。**

## 现象（2026-10-28，W3 补测试）

W3 的缺陷图上应该找到 **6 个焊点**（5 个完整的 + 1 个虚焊的）。
第一版断言写得很自然：

```cpp
check(pads.size() == 6, "找出 6 个焊点");
```

它**绿了**。

然后我按课后练习把面积门槛从 1000 改成 800 ——
**变成了 8 个**。

一个数，改一个参数就翻。⇒ 它不是图的事实，是**那个参数的产物**。

## 真凶：标注不该毁掉它要标注的东西

去查那多出来的两块是哪来的，查到了**红色标记**。

偏移焊点画在 (220,130)，它**应该在**的位置是 (200,100) ——
两个矩形**有 60×50 的重叠**。
而偏移标记画的是一个**完整的红色空框**，正好画在 (200,100,80,80) 上：

```cpp
cv::rectangle(img, offsetOriginal, cv::Scalar(0, 0, 255), 2);  // 红色空框
```

空框的**右边和下边因此压在焊点上面**，把那块金色切成了三块：

```
1602（角上那块，58×48）  +  918  +  876
```

后两块**刚好卡在 1000 的面积门槛下面**。

于是「6 个」这个数，是**门槛恰好落在 918 和 876 之间**的结果。

> **标注不该毁掉它要标注的东西。**
>
> 一个用来**说明**缺陷的标记，如果**盖在**那个缺陷上，
> 它就把缺陷改成了另一个东西 ——
> 而判据量的是**改完之后**的那个东西。

而且那个偏移缺陷，在轮廓这一层**根本认不出来**：
活下来的只是角上 58×48 的一块。

## 收法：改图 + 改断言，两件一起

**改图**：完整的空框换成**原位置左上角的 L 形角标**，
再加一根指向实际位置的短线（**线头收在焊点外面 2 像素**，不许碰到焊点）。
改完实测：偏移焊点保持完整的一块，面积 3816。

**改断言**：`== 6` 这条**不够**。换成了
**门槛在 20 倍范围里动，个数都不变**：

```cpp
for (double limit : {100.0, 300.0, 600.0, 1000.0, 1500.0, 2000.0}) {
    if (findPads(mask, limit).size() != pads.size()) stableCount = false;
}
```

这条断言断的不是「现在是 6」，是「**6 这个数不依赖门槛**」。

> ⚠ 上界为什么停在 2000：虚焊那个焊点的面积是 2342 ——
> 门槛一高它先走（实测 3000 时只剩 5 个）。
> 「6 个」这个数成立的范围是 **100 ~ 2341**，
> 所以断言扫的是这个范围**里面**的一段。
> ⇒ **稳定性也有边界**，边界要**量出来**再写上去，
> 不是「扫得越宽越好」。

## 为什么这条比「把数改对」值钱

把数从 6 改成 8，是**把 bug 藏起来** ——
下一次改门槛，它又会变成别的数，而断言也跟着改。

断「稳定性」则是**把结论的根**钉住：
只要有一块金色被切碎，**任何**门槛下个数都会不一致
（或者更糟：一致，但一致在一个错误的数上）。

> **一条断言要断的是「结论不依赖参数」，不是「结论等于某个数」。**
> 前者对参数变动免疫，后者每改一次参数就要跟着改一次。

## 推论：一个只数数量的检查器等于没有检查器

这一轮顺带撞到的一件事：

「找到 6 个」这种断言，**哪怕把图换成一张全是空白的图也能过**。

所以同一个套件里还必须断**位置和形状**：

- 缺失焊点的位置上**没有**焊点；
- 偏移的焊点是在**偏移后**的位置被找到的（实测最近 3.9 像素），
  **而且没有出现在**它原来的位置（实测最近 36.6 像素）；
- 虚焊的焊点：找到了、面积比完整焊点小、**外接矩形仍然是整块**。

⇒ **数量是结果，位置和形状才是事实。**

## 检查清单

- [ ] 这个结论**换个参数**还成立吗？（门槛、阈值、窗口大小、时间、种子……）
- [ ] 如果不成立 —— 它是**事实**，还是**那个参数的产物**？
- [ ] 断言写的是「等于 N」，还是「**在范围内稳定**」？
- [ ] 稳定性断言的**范围**是量出来的吗？（扫太宽会撞上别的边界）
- [ ] 这个数是不是**只数数量**？位置和形状断了吗？
- [ ] 图上的**标记**有没有盖住它要标注的东西？
