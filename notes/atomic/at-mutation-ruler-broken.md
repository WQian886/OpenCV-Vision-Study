# 变异活下来时，先怀疑尺子，别怀疑实现

## 补充关系
本文是「变异测试：把 bug 放回去验证」的**续篇**。
那篇讲"怎么做变异测试"，本文讲"变异活下来意味着什么"。

## 核心
2026-10-09 那一轮，9 个变异里 4 个活下来了。
查下去**全部是断言本身写错了**，实现是对的。

**测量的对象错了，而不是被测代码错了。**

## 三种"尺子坏了"

### 1. 拿范围检查代替量纲检查

想验证 `gold_pct` 是百分比，写了：
```cpp
check(p >= 0 && p <= 100, "是百分比");
```
裸像素数也落在 0~100。**变异活着。**

加一条面积上限 `p/100*roiArea <= roiArea` 仍然放行 ——
因为真实变异是去掉 `100.0 *`，而 `/roiArea` 在**下一行**，
它产出的是**分数**（0~1）。分数当然也过 0~100。

> 按错误的假设写检查，等于没检查。
> 先确认被测代码的**失败形态到底长什么样**，别照想象中的形态写。

### 2. 刺激够不到判据的门

想验证"板面基色逐图估计"，做法是给图换一套板色。
实测：换色把板面从 (50,90,40) 变成 (80,45,52)，
V 下界只从 72 挪到 **64**；而金层像素 V 在 **180~255**。
位移跨不过任何一个像素 → 必然"没变化"。

**判据没写错，是尺子不够长。**

> 做法：先量判据的**行程**（边界离最近样本有多远），
> 再挑落在这个行程内的刺激。
> 测不到 ≠ 不存在，先确认自己够得着。

### 3. 拿会跟着漂的量做基准

```cpp
check(hi <= lo * 2, "放大端不爆炸");
```
但 `hi` 和 `lo` 都由同一个参数驱动 —— 参数一变，比值不变。
变异永远活着。

> 要么钉**逐档黄金值**，要么找一个变异改不到的独立基准。

### 4. 量的是库，测的不是你（2026-10-26 补）

```cpp
cv::Mat sg, sb;
cv::GaussianBlur(step, sg, cv::Size(9, 9), 0);     // <- 直接调 OpenCV
cv::bilateralFilter(step, sb, 9, 75, 75);           // <- 直接调 OpenCV
check(bandB <= 1, "双边保住阶跃边缘");
```

这条断言量的是 **`cv::bilateralFilter` 的输出**，
而被测的是 **`w2::bilateralDenoise`** —— 我们的函数。

把 `w2::bilateralDenoise` 的**整个实现**换成高斯，
**这条断言照样绿**。

> 它证明的是「OpenCV 的双边滤波保边缘」，
> 它要证明的是「**我们的**双边滤波保边缘」。
>
> 这两件事**长得一模一样**，但**根本不是一件事**。

**这一条最阴**：它**永远绿**，
而且测的偏偏是**这个项目最核心的那条性质**。
⇒ 一个永远绿的断言比没有断言更坏：
**没有断言你知道那里没测；永远绿的断言你会以为那里测过了。**

**修法**：**造输入**可以用库函数，**量输出**必须走被测的那一层：

```cpp
const cv::Mat sb = w2::bilateralDenoise(step, 9, 75, 75);
```

完整记录：`notes/atomic/at-the-assertion-measures-the-library-not-you.md`。

## 推论：基准不能来自被测对象

同一轮发现的更隐蔽的一种：
```cpp
QString refGoldPct;                       // 从 inspect.run() 读
...变异之后...
check(now == refGoldPct, "应相等");        // 两边一起缩放 → 恒成立
```
基准和被测对象同源，变异后**两边一起变**，照样相等。

**验证 A 的断言，基准不能来自 A。**

修法：测试自己调底层函数**独立重算**期望值，再和算子报的数比。

## 两条纪律

1. **变异活下来 → 先怀疑尺子。**
   本轮 4 个存活，查下去 3 个是断言写错、1 个是刺激不够。

2. **断言红了 → 也先怀疑尺子。**
   本轮两次红都是我自己写错：
   断言"1.5x 与 2.0x 必须相等"，实测是 10 vs 11 ——
   我把探针**另一组档位**（0.4/0.8/1.4/1.6）的结论
   当成了这组（0.5/1.0/1.5/2.0）的。

> 断言和它的依据必须对着看一眼。

## 成本权衡（值得单独权衡）

逐档钉黄金值（7/10/10/11）抓得住单档偏移，但**换张图就红**。
这是拿**可维护性换检出率**。

替代方案：只钉不变量（"放大端不许爆炸"），
接受检不出只动一档的变异（M16/M18）。

没有普适答案，取决于这套测试要活多久。
