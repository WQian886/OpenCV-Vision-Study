## 📚 知识点

### 边缘 vs 轮廓

| | 边缘 (Edge) | 轮廓 (Contour) |
|---|---|---|
| 是什么 | 单个像素（梯度大的位置）| 连成线的像素集合 |
| 输出 | 二值图，每个白色像素是边缘 | 闭合曲线的点列表 |
| 类比 | 示波器上电压突变点 | 把突变点连起来形成波形线 |

### Canny 边缘检测（工业首选）

```cpp
cv::Canny(src, dst, lowThreshold, highThreshold);
```

**双阈值原理**：
- 强梯度（> highThreshold）→ 一定是边缘
- 弱梯度（< lowThreshold）→ 一定不是边缘
- 中间梯度 → 跟边缘连通才算

**经验**：低:高 ≈ 1:3（比如 50:150）

### findContours

```cpp
cv::findContours(image, contours, hierarchy, mode, method);
```

| 参数 | 常用值 | 含义 |
|---|---|---|
| mode | `RETR_EXTERNAL` | 只找最外层（焊点用这个）|
| mode | `RETR_TREE` | 找所有层级（嵌套轮廓用）|
| method | `CHAIN_APPROX_SIMPLE` | 压缩冗余点（推荐）|

### 轮廓属性

| 属性 | API | 用途 |
|---|---|---|
| 面积 | `cv::contourArea(c)` | 过滤小噪点 |
| 外接矩形 | `cv::boundingRect(c)` | 标注/裁剪 |
| 最小旋转矩形 | `cv::minAreaRect(c)` | 倾斜物体 |
| 中心点 | `cv::moments(c)` + m.m00 | 定位/对齐 |
| 周长 | `cv::arcLength(c, true)` | 形状判断 |

### 形态学操作

| 操作 | 公式 | 用途 |
|---|---|---|
| 腐蚀 erode | 缩小亮区 | 去小白点 |
| 膨胀 dilate | 扩大亮区 | 补小黑洞 |
| 开运算 open | 先 erode 后 dilate | **去小噪点**（保形状）|
| 闭运算 close | 先 dilate 后 erode | **补小洞**（保形状）|
| 形态学梯度 | dilate - erode | 边缘提取 |

**电气类比**：
- 开运算 = RC 低通滤波（去毛刺）
- 闭运算 = 施密特触发器回滞（去抖动）

> 🔧 **为什么处理链被拆出去了**：
> 它原本整段写在 `main.cpp` 里，中间隔着 `imshow` / `waitKey` / `imwrite`
> —— **一个要开窗口的函数没法做无头测试**。
> 现在处理链在 `edge_pipeline.cpp`，**demo 和测试调的是同一份源码**
> （同一个 `edge_pipeline.cpp` 链进两个目标），
> **一条都不许在 `tests/` 里再重写一遍** —— 重写就是"抄副本"。
>
> 顺带解决了另一个问题：**常量以前散在 `main.cpp` 里**，
> 现在面积门槛、Canny 阈值、形态学核大小**只在 `edge_pipeline.cpp` 里定义一次**。

> ⚠ **「合成 PCB 图的事实」现在只有一份**：`common/pcb_sim/pcb_sim.h`
> （焊点颜色、板面底色、噪声强度、图的尺寸、**金色的 HSV 窗口**）。
> W2 和 W3 都从它取 —— 起因是 W3 的 `main.cpp` 里**抄了一份** HSV 窗口，
> 而那行代码的注释偏偏写着「复用 W2 思路」。
> **注释说复用，代码是抄的** —— 而两份各自的测试**都是绿的**，
> 因为每一份都只对着自己那份图断言，谁也没跨过去看一眼。

> ⚠ **这张图上的红色标记是「L 形角标」，不是完整的红框**：
> 偏移焊点画在 (220,130)，它**应该在**的 (200,100) 和它有 60×50 的重叠 ——
> 完整的红框会**压在焊点上面**，把那块金色切成三块

> 于是「找到 6 个焊点」这个数就变成了**门槛的产物**：
> 门槛改成 800 就变成 8 个。

## ✏️ 课后练习

1. **改最小面积**：把 `kMinPadArea` 从 1000 改成 100，看有什么小噪点漏过来
   （提示：门槛低到 100 时，实测个数**不变** —— 面积噪声本来就在 1000 附近；
   而**门槛一旦高过 2342**，虚焊那个焊点就先走了，个数从 6 掉到 5）
2. **改形态学**：把 kernel 从 3×3 改成 5×5，去噪更强但焊点边缘会被吃掉
3. **加闭运算**：在开运算后再做一次闭运算，看能否修复"虚焊"（部分像素缺失的金色焊点）
4. **改 Canny 阈值**：把 50/150 改成 30/100，检测更多弱边缘
   （⚠ 在**二值 mask** 上改阈值**一个边缘都不会多** —— 梯度只有 0 和 255 两档；
   要看阈值的作用得拿**灰度图**去跑）
5. **找最小焊点**：用 `std::min_element` 找面积最小的焊点
6. **统计信息**：把每个焊点的中心点坐标 (x, y) 也打印出来
