# W2 学习笔记：色彩空间 + 滤波 + 阈值 — 术语详解

> 📌 **给电气工程师的图像处理术语速查卡**——W2 出现的 8 个核心术语，每个讲"是什么 / 原理 / 结果 / 类比"。

---

## 🎭 颜色提取（窗口 1）

### 1️⃣ Mask（二值掩码）

**是什么**：一张只有黑/白的图。白色 = "匹配条件"，黑色 = "不匹配"。

**原理**：对每个像素问 N 个条件，全是 → 白，任一不是 → 黑。

**电气类比**：施密特触发器——给信号，判断在不在阈值范围内，输出"是/否"二值。

**PCB 用途**：颜色提取的**核心产物**，后续数焊点就是数白色连通区域。

---

### 2️⃣ Bitwise AND（按位与）

**是什么**：**保留原图中"是金色"的像素，其他全涂黑**。

**原理**：`output = 原图 AND mask`（mask 是 0/255 的二值图）

**电气类比**：带使能端的采样保持器——只有 mask=1 时信号才通过。

**mask vs 金色区域**：
- mask: 1 通道，只有"是/否"
- 金色区域: 3 通道，保留原图颜色和细节

---

## 🛢️ 滤波去噪（窗口 2）

### 3️⃣ 高斯滤波（GaussianBlur）

**原理**：5×5 高斯核做加权平均，**中心权重大，边缘权重小**。

**电气类比**：低通滤波器（LPF）——滤高频噪声，但边缘也糊了。

**PCB 用途**：一般不用 PCB 检测（边缘糊掉），但 OCR 前轻度模糊可提升识别率。

---

### 4️⃣ 中值滤波（medianBlur）

**原理**：每个像素 = 邻域排序后的**中位数**。异常值（0 或 255 的椒盐噪声）排序后在两端，对中位数无影响。

**电气类比**：多次采样去极值取中间——比单次采样稳，比平均采样抗异常。

**PCB 用途**：✅ **去椒盐噪声**（传感器坏点、镜头脏点）。

---

### 5️⃣ 双边滤波（bilateralFilter）

**原理**：权重 = 空间权重 × 值差异权重。
- 空间近 + 颜色相近 → 权重高
- 跨边缘的像素因"颜色差大" → 权重低 → **不参与平均 → 边缘保留**

**电气类比**：自适应滤波器——根据信号相关性动态调整权重。比固定 LPF 强。

**PCB 用途**：✅ **PCB 检测首选**，降噪同时保边。W2 输出里双边差异最小但保边最强就是证据。

---

## ⚖️ 阈值二值化（窗口 3）

### 6️⃣ 全局阈值 @127（Global Threshold）

**原理**：单一阈值（127 = 0~255 中点），pixel<127 黑，≥127 白。

**电气类比**：单限比较器——V_in < V_ref 低，V_in > V_ref 高。

**PCB 用途**：⚠️ 光照均匀时凑合用，不均时漏检。

---

### 7️⃣ 自适应阈值（Adaptive Threshold）

**原理**：每个像素的阈值 = 邻域均值 - 常数 C。局部动态算。

**电气类比**：AGC（自动增益控制）——根据当前幅度自动调整参考电平。

**PCB 用途**：⚠️ **反而不好用**——会把背景阴影当前景。W2 输出 162300 前景像素就是证据（太多）。

---

### 8️⃣ Otsu 自动阈值 ⭐

**原理**：
1. 算灰度直方图
2. 遍历 0~255 所有可能分界值
3. 算每个的"类间方差"
4. 选最大的那个

**电气类比**：自适应比较器——根据信号统计自动设 V_ref。直方图双峰时特别准。

**PCB 用途**：✅ **PCB 检测黄金搭档**——PCB 直方图天然双峰（焊点 vs 背景）。

---

## 🎯 8 个工具决策表

| 目标 | 选哪个 | 为什么 |
|---|---|---|
| 数特定颜色元件（焊点）| HSV + mask | 颜色提取最准 |
| 去椒盐噪声 | medianBlur | 抗异常值 |
| 去热噪声 + 保边缘 | bilateralFilter ⭐ | 工业视觉首选 |
| 模糊（OCR 前）| GaussianBlur | 简单快 |
| 光照均匀二值化 | Global@127 | 最简单 |
| 光照不均二值化 | Adaptive | 但 PCB 不推荐 |
| 双峰直方图二值化 | Otsu ⭐ | PCB 检测首选 |

## 🔬 PCB 检测典型管线

```
原始 PCB 图
   ↓ bilateralFilter       ← 去噪保边
   ↓
   ↓ cvtColor → HSV         ← 转色空间
   ↓
   ↓ inRange(金色HSV)       ← 提取焊点 → mask
   ↓
   ↓ bitwise_and            ← 得到金色区域
   ↓
   ↓ threshold(Otsu)        ← 进一步二值化
   ↓
清晰"焊点 vs 背景"二值图 → W3 数焊点
```

---

## 📚 一句话总结 W2

**mask = 颜色二值化, 高斯/中值/双边 = 3 种去噪策略, 阈值 = 3 种二值化方法。PCB 检测黄金组合: bilateral + HSV + Otsu。**
